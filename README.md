# 🐾 Veterinary Management System - Frontend

Frontend del sistema de gestión integral para clínicas veterinarias, desarrollado con **React**. Este proyecto tiene como objetivo ofrecer una interfaz moderna, intuitiva y escalable para administrar las operaciones diarias de una clínica veterinaria, mejorando la experiencia tanto del personal administrativo como del equipo médico.

## 📖 Descripción

La aplicación está diseñada para centralizar la administración de clientes, mascotas, consultas, citas, productos, pagos y demás procesos relacionados con la operación de una veterinaria. Su arquitectura busca facilitar el mantenimiento del proyecto y permitir la incorporación de nuevas funcionalidades conforme evolucionen los requerimientos del negocio.

Este repositorio corresponde exclusivamente al **Frontend** del sistema y será integrado con la aplicación Backend mediante una API REST.

## ✨ Características principales

* Gestión de clientes y expediente de mascotas.
* Administración de citas mediante calendario.
* Control de consultas, tratamientos y servicios veterinarios.
* Gestión de productos, inventario, promociones y precios.
* Registro y administración de pagos utilizando distintos métodos.
* Manejo de roles y permisos según el perfil del usuario.
* Generación de documentos y reportes relacionados con la atención veterinaria.
* Diseño responsive orientado a una experiencia de usuario fluida.

## 🛠️ Tecnologías

* React
* JavaScript / TypeScript *(según la evolución del proyecto)*
* React Router
* Axios
* Tailwind CSS 
* Vite

## 📐 Objetivos del proyecto

El desarrollo seguirá una serie de buenas prácticas con el propósito de mantener un código limpio, reutilizable y fácil de mantener.

Entre ellas se incluyen:

* Arquitectura modular y escalable.
* Separación de responsabilidades.
* Componentes reutilizables.
* Consumo desacoplado de APIs.
* Manejo centralizado del estado de la aplicación.
* Buenas prácticas de accesibilidad y experiencia de usuario.
